Unreal Engine • C++ • Gameplay Systems • AI Design
--------------------------------------------------

I am a gameplay programmer and systems designer specialising in gameplay systems and mechanics. Most of my work is built in Unreal Engine using C++ and Blueprints, where I develop gameplay features, AI behaviour, and modular systems. I enjoy exploring how players interact with systems and how simple rules can create interesting outcomes. I like projects that combine strong atmosphere with mechanical depth.

* 🌍  I'm based in Wales 🏴󠁧󠁢󠁷󠁬󠁳󠁿
